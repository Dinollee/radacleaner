# Research Brief: Rada Schedule Sources

## Question
What data sources exist for obtaining schedules of the Verkhovna Rada of Ukraine — plenary sessions, committee meetings, voting sessions, and other parliamentary calendar events — for filling a calendar in the radacleaner project?

## Scope
- Official VRU website (rada.gov.ua) and its subsections
- VRU open data / API endpoints
- Committee schedule pages
- Legislative calendar / session periods
- Any other publicly available schedule sources

## Time frame
- Current session period (2026)
- Historical patterns for recurring schedules

## Audience
Developer integrating schedule data into radacleaner dashboard calendar

## Depth
standard

## Today
2026-07-08

## Angles
1. Official VRU website schedule pages and their structure
2. VRU API endpoints for schedule/calendar data
3. Plenary session schedules and session periods
