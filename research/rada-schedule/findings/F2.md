# F2: VRU API endpoints for schedule data

## Findings

### [1] The Verkhovna Rada Open Data Portal provides free API access at data.rada.gov.ua with no authentication required
- quote: "Доступ до API відбувається анонімно без обмежень, але якщо система захисту інфрастуктури раптом заблокує ваш IP, зверніться до адміністратора Порталу для реєстрації IP вашої системи у "білому списку""
- url: https://data.rada.gov.ua/open/main/api
- source_type: primary
- published: unknown
- confidence: high

### [2] The "zal" dataset (Інформація про розгляд питань порядку денного) contains plenary session chronology, voting results, and agenda items updated hourly
- quote: "Результати голосування, виступи, питання порядку денного, хронологія за скликаннями"
- url: https://data.rada.gov.ua/open/data/zal
- source_type: primary
- published: 2015-04-21 (created), 2026-07-04 (last publish)
- confidence: high

### [3] Schedule data is available via the legacy w1.c1.rada.gov.ua/pls/radan_gs09/ system with parameterized URL endpoints for any date
- quote: "http://w1.c1.rada.gov.ua/pls/radan_gs09/ns_h2?day_=08&month_=07&year=2026&nom_s=15"
- url: https://w1.c1.rada.gov.ua/pls/radan_gs09/ns_h1
- source_type: primary
- published: unknown
- confidence: high

### [4] The "meetings" dataset provides plenary session agendas, transcripts, and operational information organized by convocation (sklykannya)
- quote: "Тексти стенограм пленарних засідань, порядків денних, оперативна інформація, календар проведення пленарних засідань, довідники сесій за скликаннями, загальна інформація тощо"
- url: https://data.rada.gov.ua/open/data/meetings
- source_type: primary
- published: 2017-07-19 (created), 2026-07-08 (last build)
- confidence: high

### [5] Data is available in CSV, JSON, and XML formats with content-negotiation via file extension appended to the dataset ID
- quote: "Для цього потрібно знати внутрішній id (або глобальний guid) ідентифікатор набора даних та додати до її звичайної URL адреси потрібний формат через кому"
- url: https://data.rada.gov.ua/open/main/api/page2
- source_type: primary
- published: unknown
- confidence: high

### [6] The plenary calendar at w1.c1.rada.gov.ua shows scheduled session days with links to detailed daily agendas including vote counts (for/against/abstain/not participating)
- quote: "Результати: за-160 проти-4 утримались-1 не голосували-125 відсутні - 66"
- url: https://w1.c1.rada.gov.ua/pls/radan_gs09/ns_h2?day_=01&month_=07&year=2026&nom_s=15
- source_type: primary
- published: unknown
- confidence: high

### [7] The open data portal contains 610 total datasets across multiple categories including plenary sessions, legislation, and MP activity
- quote: "Реєстр відкритих даних (Портал відкритих даних Верховної Ради України) — 610 наборів"
- url: https://data.rada.gov.ua/open/main/dataset
- source_type: primary
- published: unknown
- confidence: high

### [8] The "zal" dataset hierarchy includes 8 convocation-specific sub-datasets (III-IX sklykannya) with 140 total datasets for tracking agenda item review chronology
- quote: "Хронологія розгляду (за скликаннями) [140]" 
- url: https://data.rada.gov.ua/ogd/zal/list.json
- source_type: primary
- published: 2026-07-04
- confidence: high

### [9] The meetings dataset provides separate data streams: agendas (27 datasets), transcripts (27 datasets), coordination councils (27 datasets), and operational info (27 datasets)
- quote: "Порядки денні пленарних засідань [27], Стенограми пленарних засідань [27], Стенограми погоджувальних рад [27], Оперативна інформація [27]"
- url: https://data.rada.gov.ua/open/data/meetings
- source_type: primary
- published: unknown
- confidence: high

### [10] The nom_s parameter in the legacy system corresponds to convocation number (15 = IX convocation, current)
- quote: "15-те скликання" (visible in page header when accessing ns_h2 endpoint)
- url: https://w1.c1.rada.gov.ua/pls/radan_gs09/ns_h2?day_=08&month_=07&year=2026&nom_s=15
- source_type: primary
- published: unknown
- confidence: high

## Dead ends

- The committee meeting calendar endpoint (ns_kom_h1) returned HTTP 403 Forbidden - committee meeting data may require different authentication or may not be publicly accessible via this endpoint
- The RTF export endpoints are available but require constructing URLs with specific day/month/year parameters

## Suggested follow-ups

1. Investigate committee meeting data availability - is it accessible through a different endpoint pattern or does it require special access?
2. Explore the "zpr" (zakonoproekty/bills) dataset structure to understand how voting records are linked to specific bills and their schedules
3. Check if there's a real-time or near-real-time streaming API for live session monitoring (the "operational info" datasets might provide this)
