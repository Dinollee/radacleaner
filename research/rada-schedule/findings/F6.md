# F6: Alternative and third-party schedule sources

## Findings

### [1] OpenAustralia scraped Rada vote data via morph.io from w1.c1.rada.gov.ua endpoints
- quote: "This is a scraper that runs on morph.io to collect details of every recorded vote in the Ukrainian parliament... Calendar of sitting days: http://w1.c1.rada.gov.ua/pls/radan_gs09/ns_el_h"
- url: https://github.com/openaustralia/ukraine_verkhovna_rada_votes
- source_type: community
- published: archived Jun 2026 (inactive since Sep 2017)
- confidence: high

### [2] The old Rada website (w1.c1.rada.gov.ua) still hosts plenary session calendars and vote details via query parameters
- quote: "Plenary session day with votes: http://w1.c1.rada.gov.ua/pls/radan_gs09/ns_el_h2?data=02092015&nom_s=3"
- url: http://w1.c1.rada.gov.ua/pls/radan_gs09/ns_el_h
- source_type: primary
- published: unknown (legacy system, still referenced by scrapers)
- confidence: high

### [3] Rada4you.org provides a REST API (v1) for parliament activity data including deputies, votes, and divisions
- quote: "Ukrainian parliament activity API client... We are using API v1, documentation should be accessible by url https://rada4you.org/help/data"
- url: https://github.com/duckoder/rada4you
- source_type: community
- published: archived Dec 2022 (service currently down)
- confidence: medium

### [4] The official Rada portal (rada.gov.ua) publishes plenary schedules, committee meeting calendars, and voting statistics
- quote: "Пленарні засідання > Порядки денні пленарних засідань > Тижневі графіки засідань комітетів"
- url: https://rada.gov.ua
- source_type: primary
- published: current (active site as of Jul 2026)
- confidence: high

### [5] itd.rada.gov.ua hosts the bill search system with search, filtering by date, author, and status
- quote: "Законопроєкти > Пошук за реквізитами > Зареєстровано за потичний тиждень > На опрацюванні в комітетах > Прийняті акти"
- url: https://itd.rada.gov.ua/billInfo/Bills/SearchResults
- source_type: primary
- published: current (active as of Jul 2026)
- confidence: high

### [6] data.gov.ua (Ukraine's open data portal) has zero datasets specifically about the Verkhovna Rada
- quote: "Не знайдено жодного набору даних для 'верховня рада'"
- url: https://data.gov.ua/dataset?q=%D0%B2%D0%B5%D1%80%D1%85%D0%BE%D0%B2%D0%BD%D1%8F+%D1%80%D0%B0%D0%B4%D0%B0
- source_type: primary
- published: current (portal active, but no Verkhovna Rada datasets)
- confidence: high

### [7] zayn303/rada-watch is an active AI-powered parliament tracker scraping bill summaries and voting patterns
- quote: "AI-powered Ukrainian parliament tracker — bill summaries, MP voting patterns, promise tracker"
- url: https://github.com/zayn303/rada-watch

- published: updated Jun 2026 (6 commits, active project)

- quote: "Новини парламенту / Новини комітетів / Новини фракцій та груп"
- url: https://www.pravda.com.ua/eng/news/

- published: current (active Jul 2026)
- confidence: low (news, not structured schedule data)

## Dead ends
- data.gov.ua search for "верховня рада" returns 0 results — the portal focuses on local councils and executive agencies, not parliament
- rada4you.org service is currently down (transport error) — was a third-party API for parliament activity aggregation
- GitHub topics "verkhovna-rada" and "rada-ukraine" have zero public repos tagged
- itd.rada.gov.ua bill search returns 405 on GET requests (requires POST or different endpoint)

## Suggested follow-ups
- Investigate the exact POST request format for itd.rada.gov.ua bill search to understand what schedule data can be programmatically retrieved
- Check if data.rada.gov.ua (the Rada's own open data portal, separate from data.gov.ua) has API endpoints — the rada2kaggle repo references it
- Research whether the Coordination Council ("Погоджувальна рада") meetings at rada.gov.ua follow a predictable weekly pattern that could be scraped for schedule prediction
