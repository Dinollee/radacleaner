# Research: EU Negotiation Clusters — Stable Data Sources

## Question
Джерела даних для автоматичного відстеження статусу переговорних кластерів України з ЄС. Потрібні стабільні, оновлювані API або скраперабельні сторінки.

## Scope
- Official EU sources (Council, Commission, Parliament)
- Ukrainian government sources (Stefanishyna office, MFA, RADA)
- Third-party trackers (think tanks, news aggregators)
- API availability, update frequency, reliability

## Assumptions
- Data source must be free (no paid APIs)
- Should update at least monthly
- Preferably machine-readable (API, RSS, structured HTML)

## Depth: standard
- 3-5 sub-agents, 15+ sources

## Date: 2026-07-08

## Angles
1. EU Council official documents and press releases
2. European Commission enlargement reports and API
3. Ukrainian government tracking (Stefanishyna, MFA)
4. Third-party trackers and think tanks
5. News aggregators and RSS feeds
