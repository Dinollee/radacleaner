# F5: News sources and RSS feeds for Ukraine EU negotiation clusters

## Findings

### [1] European Pravda (Європейська правда) — PRIMARY source for cluster news
- **URL**: https://www.eurointegration.com.ua/
- **English**: https://www.eurointegration.com.ua/eng/
- **Section**: "Вступ до ЄС" (EU Accession) section visible in top navigation
- **Coverage**: Dedicated team covering EU accession negotiations exclusively. Breaking news on cluster openings.
- **Key evidence (July 8, 2026)**: Headline "ЄвроПравда дізналася, коли відкриють наступний кластер для України" — European Pravda broke the story about the next cluster opening date.
- **Key evidence (July 3, 2026)**: "Media: Hungary reportedly unblocks opening of sixth EU accession talks cluster with Ukraine"
- **Key evidence (July 1, 2026)**: "Halfway to the deadline, Ukraine scores 15% on the EU's priority reforms plan"
- **RSS feed**: NOT found. Tried `/rss`, `/rss/news.xml`, `/rss/articles.xml`, `/rss/all.xml`, `/eng/rss/all.xml`, `/eng/rss` — all return 404.
- **Scraping**: Article URLs follow pattern `eurointegration.com.ua/news/YYYY/MM/DD/{id}/`. HTML is clean and extractable.
- **Confidence**: HIGH — this is the single most important source for cluster opening news. Breaks exclusives.
- **Update frequency**: Multiple articles daily on EU/Ukraine topics.

### [2] Ukrainska Pravda — RSS feed CONFIRMED working
- **URL**: https://www.pravda.com.ua/
- **RSS URL**: https://www.pravda.com.ua/rss/view_news/ ✅
- **Feed format**: RSS 2.0 with `<content:encoded>` (full HTML), `<dc:creator>` (author), `<pubDate>`, `<enclosure>` (images)
- **Feed content**: Recent news items, including EU-related articles that cross-reference European Pravda
- **TTL**: 60 minutes (auto-refresh)
- **Coverage**: General Ukrainian news. EU cluster articles appear when they're breaking news. Often cites European Pravda as source.
- **Key example**: Article about Babish/PURL program cited European Pravda source directly in content.
- **Limitation**: No dedicated EU section filter in RSS — must parse all items for EU/cluster keywords.
- **Confidence**: HIGH — reliable RSS with structured XML data.

### [3] Ukrinform — state news agency, no RSS found
- **URL**: https://www.ukrinform.net/
- **RSS**: Tried `/rss`, `/rss/polytics`, `/block-rss`, `/block-last/rss` — ALL return 404 or redirect to 404 page.
- **Newsletter**: Has Substack newsletter at https://ukrinformsubscription.substack.com/
- **Telegram**: @ukrinform_news
- **Coverage**: State news agency, has "Politics" section. Some EU coverage but less focused on cluster negotiations.
- **Confidence**: MEDIUM — no programmatic RSS, but Substack newsletter and Telegram are alternatives.

## Dead ends
- DuckDuckGo: CAPTCHA blocked after first query — could not search for Telegram channels or additional sources
- Google: Completely blocked — Ukrainian locale redirect with no results
- European Pravda RSS: No feed found despite multiple URL pattern attempts
- Ukrinform RSS: No feed found despite site having RSS-like infrastructure (Substack newsletter)
- Council RSS: 403 Forbidden on all attempts
- Telegram channel search: No public preview of channels found via t.me/s/ pattern — all returned contact pages

## Recommended approach for cluster monitoring

### Tier 1: Must-have (scrape)
1. **European Pravda** (eurointegration.com.ua) — scrape main page + "Вступ до ЄС" section daily. This is where cluster news breaks first.
   - Pattern: search for "кластер" in article titles
   - Article URLs: `eurointegration.com.ua/news/YYYY/MM/DD/{id}/`
   - No RSS, must scrape HTML

### Tier 2: RSS feeds for supplementary signals
2. **Ukrainska Pravda RSS** (`pravda.com.ua/rss/view_news/`) — parse items mentioning "кластер", "переговори", "ЄС", "accession"
3. **Ukrinform Telegram** (@ukrinform_news) — monitor via Telegram API for cluster mentions

### Tier 3: Manual/periodic checks
4. **EU Council** (consilium.europa.eu) — manual check after each Council meeting
5. **European Commission** (ec.europa.eu/commission/presscorner) — manual check for enlargement reports
6. **Ukrainian MFA** — manual check for Stefanishyna office statements
